October 7, 2026 by Ashani Falconer

This semester I started INFO2180 and have been learning the fundamentals of web development. One of the first things we explored was HTML, which provides the structure for web pages. Although creating a webpage may seem simple at first, there are many elements and best practices that help make content organized and accessible.

As I continue learning, I am becoming more familiar with semantic HTML elements such as headers, articles, sections, and footers. These elements make webpages easier to understand and maintain. I am excited to learn more about CSS and JavaScript and how they can be used to create interactive and visually appealing websites.
